# Changelog

All notable changes to Kobo are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- Dashboard chart axes use round steps.
- Empty activity, budget, and account screens say what to do next.
- Activity filters include a start date and an end date.
- Secondary lines use the muted theme color.

## [1.0.0] - 2026-11-14

### Added

- Accounts for cash, bank, and mobile money, in more than one currency.
- Income, expense, and transfer transactions, including repeating rules.
- Monthly category budgets with an over-budget alert.
- An offline naira rate table, and an optional live rate fetch.
- Dashboard charts for spending, cash flow, and net worth.
- Search, CSV import and export, and light, dark, and system themes.
- A seeded demo book so the first launch is not an empty form.
